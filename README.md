# Restaurant AI Chatbot - Zaiqa

An advanced AI-powered restaurant chatbot built with n8n and Groq (Llama).

## Features
- AI assistant named "Zaiqa"
- Full menu with prices
- Reservation booking system
- Replies in English and Urdu
- Remembers conversation history
- Business hours information

## Menu
- Chicken Biryani: Rs. 350
- Mutton Karahi: Rs. 650
- Nihari: Rs. 400
- Naan: Rs. 30
- Lassi: Rs. 80

## Tools Used
- n8n
- Groq API (Llama 3.3)
- Simple Memory
